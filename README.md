# 감사맥락AI

낯선 회사의 거래 구조를 신뢰 가능한 근거로 이해하고, 이를 계정·감사위험·요청자료·인터뷰 질문으로 연결하는 감사 준비 도구입니다.

첫 MVP는 **여행업 / BSP 항공권 정산 / 사용제한예금** 사례에 집중합니다.

> **경고 — 실제 자료 반입 금지**
> 현재 이 저장소에는 접근제어도 암호화도 없습니다. 실제 회사명, 실제 감사조서, 은행조회서, 계약서 등
> 기밀 자료를 넣지 마십시오. 데모 사례는 가상 여행사이며, 회사 특정 사실은 전부 추정 또는 미확인으로만 존재합니다.

## 현재 상태 (2026-08-05)

**4단계 완료 + DART 회사 검색 슬라이스 진행 중**

가상 사례 (CASE-001)

- 출처 3건, 원문 스냅샷과 해시 보관 (IATA BSP 매뉴얼, IFRS 해석위원회 논의 결과)
- 골든 Claim 25건 (사실 16 / 추정 5 / 미확인 4)
- 거래 단계 6, 잠재 위험 5, 요청자료 8, 인터뷰 질문 10

실제 회사 사례 (CASE-002, 하나투어)

- DART 사업보고서(2025.12) 원문 스냅샷 3개, 해시 보관
- 회사 특정 사실 5건 (사람이 원문을 보고 승인한 것만)
- 근거 후보 85건 — 검토 대기

검사 53건 — 전부 통과 (신뢰성 20 + 화면 16 + 수집 8 + 회사 사례 9)

### 화면 3개

| 파일 | 내용 |
|---|---|
| `index.html` | 가상 여행사 BSP 거래 지도 (기본 화면) |
| `hanatour.html` | 하나투어 공시로 확인된 것과 확인되지 않은 것 |
| `candidates.html` | 근거 후보 검토 (승인 전 상태) |

## 필요한 것

- **Node.js 22.6 이상** (확인된 환경: v24.18.0)
- 처음 한 번만: `npm install` (개발 도구 3개. 화면 자체는 외부 라이브러리를 쓰지 않습니다)
- Python과 `pypdf`는 **원문 PDF가 바뀔 때만** 필요합니다

## 1. 화면 열기 — 가장 쉬운 방법

프로젝트 폴더의 **`실행하기.bat`** 을 더블클릭하십시오.

화면을 만들고 로컬 서버를 켠 다음, 브라우저가 자동으로 열립니다. 창을 닫으려면 검은 창에서 `Ctrl+C`를 누르십시오.

명령으로 하려면:

```bash
npm start
```

### 화면에서 눌러볼 것

1. 왼쪽에서 **거래 단계 1~6**을 눌러 이동합니다. 기본 화면은 채팅창이 아니라 거래 지도입니다.
2. 각 Claim의 **상태 배지**를 봅니다 — `◆ 사실`, `◇ 추정`, `? 미확인`. 색이 아니라 글자와 기호로 구분됩니다.
3. **`근거 열기`** 를 누르면 출처·등급·수집일·스냅샷 해시가 나옵니다.
4. **`원문 N쪽 열기 ↗`** 를 누르면 실제 PDF가 **해당 페이지에서** 열립니다.
5. **6단계(인가 유지: 담보 제공과 한도 관리)** 로 가면 사용제한예금 관련 위험(RK-05)이 있습니다.
6. 위험 아래 요청자료·질문의 **`출발:`** 에 있는 Claim 번호를 누르면 그 근거로 이동합니다.
7. **2단계(항공권 발권과 판매 보고)** 에서 회사 특정 Claim이 전부 추정·미확인인 것을 확인합니다.

## 2. 검사 실행

**`확인하기.bat`** 을 더블클릭하거나:

```bash
npm test
```

무엇을 검사하는지는 [docs/source-policy.md](docs/source-policy.md) §8에 있습니다. 대표적으로:

- 사실 Claim은 100% 직접 근거를 가진다
- 인용문이 지정한 페이지의 원문에 실제로 존재한다
- 산업 일반 근거로 회사 특정 사실을 만들 수 없다
- 미확인 항목은 요청자료·질문으로 전환된다
- 화면에서 회사 특정 Claim이 사실로 표시되지 않는다

## 3. 그 밖의 명령

```bash
npm run build          # 화면만 다시 만들기 (dist/)
npm run typecheck      # 타입 검사
npm run format:check   # 형식 검사
npm run seed:report    # 골든 데이터를 글로 출력
npm run review         # 검토용 표를 마크다운으로 출력
```

원문 PDF를 교체했을 때만:

```bash
python scripts/extract_pdf_pages.py
```

인용 검증용 페이지 텍스트를 다시 만듭니다. 그 뒤 `npm test`로 해시와 인용문을 다시 확인하십시오.

## 아직 없는 것

- **AI 자동 추출** — 모든 Claim은 사람이 손으로 만들었습니다
- **데이터베이스** — 시드 JSON을 직접 읽습니다 ([ADR 0001](docs/decisions/0001-defer-database.md))
- **브라우저 e2e 테스트** — 화면 검사는 생성된 HTML을 보는 방식입니다 ([ADR 0006](docs/decisions/0006-static-render-instead-of-nextjs.md))
- **PDF 업로드, Claim 검토함, 내보내기** — 다음 단계 후보입니다
