# ADR 0008 — BM 대시보드는 모든 상장사를 허용한다 (범위 변경)

- 날짜: 2026-08-05
- 상태: 승인됨 (사용자 선택)

## 뒤집는 결정

`CLAUDE.md`의 MVP 경계는 "여행업 외 산업을 추가하지 말 것"이었고, `docs/product-design.md` §12도 "다중 산업"을 제외 항목으로 두었습니다. 이 ADR이 **회사 검색과 BM 대시보드에 한해** 그 제한을 풉니다.

## 왜 뒤집는가

사업보고서는 법정 서식이라 목차와 항목이 모든 상장사에 동일합니다. 하나투어에서 만든 추출 규칙(정관 사업목적, 영업수익 구분, 판매경로, 담보제공자산, 이사회 안건…)이 다른 회사에 그대로 동작합니다. 즉 **업종을 제한해도 얻는 안전이 거의 없고, 잃는 유용성은 큽니다.**

감사인이 실제로 맡는 회사는 여행업이 아닐 가능성이 훨씬 큽니다. 대시보드가 여행업에서만 뜬다면 도구를 쓸 일 자체가 드뭅니다.

## 무엇을 허용하고 무엇을 허용하지 않는가

### 허용

- 모든 상장사(그리고 DART에 공시하는 비상장사)를 이름으로 검색
- 선택한 회사의 사업보고서를 한 건 가져와 BM 대시보드 표시
- 대시보드의 각 칸을 공시 원문 근거가 붙은 Claim으로 구성

### 허용하지 않음

- **감사 연결의 확장**: 거래 지도, 잠재 위험, 요청자료, 인터뷰 질문은 **여전히 여행업/BSP 전용**입니다. 다른 업종의 거래 온톨로지를 만들지 않습니다.
- **업종 자동 판별로 위험 생성**: 업종을 보고 위험 목록을 자동 생성하지 않습니다. 큐레이션 없는 위험은 이 제품이 하지 말아야 할 일입니다.
- 자동 크롤링, 후보의 자동 승격 (ADR 0007과 동일)

## 화면에서 지켜야 할 것

여행업이 아닌 회사를 열면 대시보드는 채워지지만 감사 연결은 비어 있습니다. 이때 **빈칸을 숨기지 않고** "감사 연결은 아직 여행업/BSP 사례만 지원합니다"라고 화면에 명시합니다. 사용자가 "이 회사는 위험이 없다"로 오해하면 안 됩니다.

## 새로 생기는 위험

- **대시보드가 완성돼 보이는 착각.** 업종이 넓어질수록 "한눈에 보이는 요약"의 유혹이 커집니다. 각 칸은 반드시 Claim 묶음이어야 하고, 자유 서술 생성을 넣지 않습니다.
- **업종별 회계 특성 차이.** 예를 들어 제조업의 재고자산과 여행업의 재고자산은 성격이 전혀 다릅니다. 대시보드는 공시에 적힌 항목명과 금액만 보여주고, 그 의미를 해석하지 않습니다.
- **검색 대상 증가.** 회사코드 파일은 약 27MB이며 로컬 캐시로 처리합니다(30일).

## 재검토 조건

- 특정 업종의 감사 연결을 추가하려 할 때 — 거래 온톨로지의 공통/업종별 계층을 먼저 설계해야 합니다
- 대시보드에 요약 문장 생성을 넣자는 요구가 나올 때 — 이 ADR의 "허용하지 않음"을 다시 검토해야 합니다
