# ADR 0003 — 저장은 영어, 화면 표기는 한국어

- 날짜: 2026-08-05
- 상태: 승인됨 (사용자 승인)

## 맥락

문서마다 상태를 `FACT`로 쓰기도 하고 `사실`로 쓰기도 했습니다. 저장값과 표시값이 섞이면 데이터 비교와 테스트가 어긋납니다.

## 결정

- 저장값(열거형, JSON, 이후 DB 컬럼)은 영어 대문자: `FACT`, `INFERENCE`, `UNVERIFIED`, `CONFLICTING`, `INDUSTRY`, `COMPANY` 등
- 화면 표기는 한국어: 사실, 추정, 미확인, 상충, 산업 일반, 회사 특정
- 대응표는 `src/domain/types.ts`의 `ASSERTION_LABEL_KO`, `SCOPE_LABEL_KO` 한 곳에만 둡니다. 화면 어디에서도 문자열을 다시 적지 않습니다.
- Claim 본문(`text`)과 위험·질문 문구는 한국어로 작성합니다. 사용자가 감사인이기 때문입니다.
- 원문 인용(`quote`)은 번역하지 않고 원어 그대로 보존합니다.

## 결과

- 얻는 것: 표시 문구를 바꿔도 데이터와 테스트가 깨지지 않음. 번역으로 인한 인용 왜곡 방지
- 비용: 화면에서 원문 인용은 영어로 보임. 필요하면 참고 번역을 **별도 필드**로 덧붙이되, 근거 대조는 항상 원문으로 합니다
