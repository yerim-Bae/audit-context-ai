# ADR 0002 — 신뢰도 점수를 화면에 표시하지 않는다

- 날짜: 2026-08-05
- 상태: 승인됨 (사용자 승인)

## 맥락

`docs/product-design.md` §7의 `claims` 테이블에는 `confidence` 필드가 있으나, 같은 문서는 "confidence는 사실/추정 상태를 대신하지 않는다. 높은 확률의 추정도 여전히 추정이다"라고 못박고 있습니다.

감사 실무에서 0.92 같은 숫자가 화면에 있으면, 그것이 무엇의 확률인지와 무관하게 "거의 사실"로 읽힙니다. 이 제품이 막으려는 오류가 바로 그것입니다.

## 결정

- `confidence` 필드를 도메인 타입과 시드 데이터에 두지 않습니다.
- 화면에도 표시하지 않습니다.
- 주장의 확실성은 오직 네 가지 상태(사실/추정/미확인/상충)로만 전달합니다.

## 예외

AI 추출 파이프라인이 도입되면 모델의 출력 확률을 **운영 로그(`generation_runs`)** 에 남길 수 있습니다. 이는 모델 품질 측정용이며 사용자 화면에 노출하지 않습니다.

## 결과

- 얻는 것: 상태 표시가 유일한 확실성 신호가 되어 해석이 흔들리지 않음
- 비용: 검토 우선순위를 자동으로 정렬하기 어려움. 대신 범위(회사 특정 우선)와 미확인 여부로 정렬
