# ADR 0005 — 단계 0에서는 npm과 Node 내장 도구만 쓴다

- 날짜: 2026-08-05
- 상태: 승인됨 (기술적 판단)

## 맥락

`CLAUDE.md`의 명령 목록은 pnpm과 Vitest를 전제합니다. 그러나 이 컴퓨터에는 pnpm이 설치되어 있지 않고(Node v24.18.0, npm 11.16.0, git 2.54.0은 설치됨), 단계 0의 산출물은 JSON 시드와 검증 테스트뿐입니다.

사용자에게 "단계 0에서는 패키지 설치가 필요 없다"고 안내한 상태이기도 합니다.

## 결정

단계 0에서는 **의존성을 하나도 설치하지 않습니다.**

- 테스트 러너: Node 내장 `node:test` (`npm test`)
- 타입: `.ts` 파일을 Node의 기본 타입 제거(type stripping) 기능으로 실행. 별도 빌드 없음
- 시드 형식: YAML 대신 **JSON** (파서 설치 불필요)
- PDF 텍스트 추출: Python 스크립트(`scripts/extract_pdf_pages.py`)를 원문이 바뀔 때만 수동 실행. 추출 결과를 저장소에 두어 테스트는 Node만으로 동작

## 한계 — 아직 하지 못하는 것

- **타입 검사(`tsc --noEmit`)는 실행하지 않았습니다.** Node는 타입을 제거하고 실행할 뿐 검증하지 않습니다. `typescript` 패키지를 설치하는 4단계에서 도입합니다.
- 형식 검사(Prettier/ESLint)도 같은 이유로 아직 없습니다.

이 두 가지는 "실행했다"고 보고하면 안 되는 항목입니다.

## 재검토 시점

4단계에서 Next.js를 도입할 때 pnpm/Vitest/TypeScript로 전환할지, npm을 유지할지 결정하고 `CLAUDE.md`의 명령 목록을 실제와 일치시킵니다.
