# ADR 0012 — 트랙을 도메인 열거값이 아니라 팩 데이터로 둔다

- 날짜: 2026-08-11
- 상태: 승인됨

## 무엇을 뒤집는가

`src/domain/pack.ts` 의 `TRACK` / `TRACK_FROM_KO` / `TRACK_LABEL_KO` / `TRACK_ORDER` / `TRACK_HIDDEN_IN_TOC` 가 **조선업 팩의 트랙으로 하드코딩**돼 있었습니다. 이 다섯을 없애고 `pack.json` 의 `tracks` 배열이 값을 정하게 합니다.

## 왜 — 두 번째 산업에서 바로 깨졌다

원전 팩을 넣자마자 빌드가 멈췄습니다.

```
Error: 팩 "nuclear" 카드 N01: 모르는 track "기업·밸류체인".
쓸 수 있는 값: 산업기초, 비즈니스, 거래구조, 기자재, 용어, 필드, 마무리
```

**설계 결함이 맞습니다.** 원전의 트랙은 조선업과 달라야 정상입니다.

| | 조선업 | 원전 |
|---|---|---|
| 트랙 | 산업기초·비즈니스·거래구조·**기자재**·용어·필드·마무리 | 산업기초·**기업·밸류체인**·**계약·수주**·거래구조·**운영단계**·**SMR**·**제약조건**·용어·필드·마무리 |

원전에는 **운영단계**(정비 60년·계속운전·해체)와 **제약조건**(웨스팅하우스 원천기술·인허가·핵연료)이 독립 트랙으로 필요하고, 조선업의 **기자재** 트랙은 성립하지 않습니다.

## 축과 트랙을 가르는 기준

이 ADR의 핵심입니다. 둘 다 카드에 붙는 분류인데 **한쪽만 팩 데이터입니다.**

| | 축 `CardAxis` | 트랙 `Track` |
|---|---|---|
| 무엇인가 | 감사인이 이 문장을 **어떻게 읽어야 하는가** | 이 산업을 **무엇으로 나눠 설명하는가** |
| 산업이 바뀌면 | 그대로 | 달라진다 |
| 어디에 사는가 | 도메인 열거값 (`INDUSTRY`·`MIXED`·`UNVERIFIED`) | 팩 데이터 (`pack.json` 의 `tracks`) |
| 왜 | 신뢰 규칙에 걸려 있다. 팩이 늘릴 수 있으면 규칙이 뚫린다 | 목차 제목일 뿐 신뢰 규칙과 무관하다 |

**축을 팩 데이터로 내리면 안 됩니다.** 축은 `Scope`·`AssertionStatus` 로 되돌아가고(`CARD_AXIS_CLAIM`), 거기서 "카드는 `FACT` 가 될 수 없다"가 강제됩니다(ADR 0010). 팩이 축을 새로 만들 수 있으면 그 규칙을 우회할 수 있습니다.

## 계약

```json
"tracks": [
  { "id": "INDUSTRY_BASICS", "label": "산업기초" },
  { "id": "VALUE_CHAIN",     "label": "기업·밸류체인" }
]
```

- 배열 순서 = 목차 순서
- `id` 는 영어 대문자 슬러그(저장), `label` 은 한국어(화면) — ADR 0003 준수
- **`tracks` 가 없으면 `DEFAULT_TRACK_DEFS` 로 동작합니다.** 조선업 팩은 이 키가 없고 그대로 돌아가야 합니다
- `FIELD` 와 `WRAP_UP` 두 id 만 화면이 특별 취급합니다 — 목차에서 감추고, 필드 점프 칩을 붙이지 않습니다. **id 를 바꾸면 화면이 깨집니다**
- id·label 중복, 빈 값은 로더가 막습니다
- 선언했는데 카드가 0장인 트랙, 선언에 없는 트랙을 쓴 카드는 **경고만 하고 빌드를 계속합니다.** 목차에서 빠질 뿐 데이터가 틀린 것은 아니기 때문입니다

## 회귀

조선업 산출물이 **바이트 단위로 동일**해야 합니다. 별도 worktree 에서 이전 코드로 빌드해 sha256 을 비교했고 같았습니다(`DA5444BC…`). 이 확인 없이 병합하면 첫 산업의 화면이 조용히 달라질 수 있습니다.

## 결과

- 얻는 것: 산업마다 자기 구조로 목차를 짤 수 있고, 남은 8개 산업이 같은 곳에서 다시 깨지지 않습니다
- 비용: `Track` 이 문자열이 되어 타입 검사가 오타를 잡아 주지 못합니다. 대신 로더가 팩 기준 허용값을 오류 메시지에 실어 막습니다
- 위험: `FIELD`·`WRAP_UP` id 를 팩이 바꾸면 화면 동작이 조용히 빠집니다. 두 id 를 상수로 뽑아 두었고 이 문서에 적었습니다

## 재검토 조건

- 팩이 `FIELD`·`WRAP_UP` 말고 다른 트랙에도 화면 특수 동작을 요구할 때 — 그때는 트랙에 `role` 같은 필드가 필요합니다
