# 용어집

이 문서는 팀원이 같은 낱말을 같은 뜻으로 쓰기 위한 기준입니다. 여기 정의된 낱말은 코드의 타입 이름과 일치합니다.

## 1. 제품 내부 용어

| 영어(저장) | 한국어(화면) | 정의 | 주의 |
|---|---|---|---|
| `Claim` | 주장 | 한 문장으로 표현 가능한 원자적 진술 한 개 | 두 가지를 말하면 두 개로 나눕니다 |
| `Source` | 출처 | 주장을 뒷받침할 수 있는 문서·페이지 등 자료 단위 | 링크만으로는 출처로 인정하지 않습니다 |
| `Snapshot` | 스냅샷 | 수집 시점의 원문을 그대로 보존한 파일과 해시 | 원문이 바뀌면 덮어쓰지 않고 새로 만듭니다 |
| `EvidenceSpan` | 근거 위치 | 스냅샷 안의 특정 위치와 그 위치의 짧은 원문 발췌 | 페이지·절이 없으면 근거로 쓰지 않습니다 |
| `TransactionStep` | 거래 단계 | 거래를 순서대로 나눈 한 마디 | 분석 틀이며, 내용은 Claim이 뒷받침합니다 |
| `AuditRisk` | 잠재 위험 | 왜곡표시가 생길 수 있는 지점 | 유의적 위험 확정이 아닙니다 |
| `RequestItem` | 요청자료 | 확인을 위해 회사에 요청할 자료 | 어떤 위험·Claim에서 나왔는지 남깁니다 |
| `InterviewQuestion` | 인터뷰 질문 | 담당자에게 물어볼 질문 | 기대하는 근거와 후속 조건을 같이 적습니다 |

## 2. 주장 상태 (assertion status)

| 저장값 | 화면 | 기호 | 뜻 |
|---|---|---|---|
| `FACT` | 사실 | ◆ | 근거 원문이 이 주장을 직접 지지하고 적용 범위가 일치함 |
| `INFERENCE` | 추정 | ◇ | 확인된 사실에서 도출했으나 직접 확인되지 않음 |
| `UNVERIFIED` | 미확인 | ? | 필요한 근거가 없어 결론을 낼 수 없음 |
| `CONFLICTING` | 상충 | ! | 둘 이상의 근거가 서로 양립하지 않음 |

색만으로 구분하지 않습니다. 글자와 기호를 항상 함께 표시합니다.

## 3. 검토 상태 (review status)

주장 상태와 **별개**입니다. 사람이 얼마나 확인했는지를 나타냅니다.

`AI_EXTRACTED`(AI 추출) → `HUMAN_VERIFIED`(사람 검토 완료) → `REJECTED`(반려) / `STALE`(오래됨)

## 4. 적용 범위 (scope)

| 저장값 | 화면 | 뜻 |
|---|---|---|
| `INDUSTRY` | 산업 일반 | 제도·업계 전반에 적용 |
| `COMPANY` | 회사 특정 | 특정 회사에만 적용 |
| `PERIOD` | 기간 특정 | 특정 기간에만 적용 |
| `TRANSACTION` | 거래 특정 | 특정 거래 유형에만 적용 |

**핵심 규칙**: 산업 일반 근거는 회사 특정 주장을 사실로 만들지 못합니다.

## 5. 출처 등급

`S` 법령·계약·조회서·원장 원본 / `A` 감독기관·산업기구 공식 문서 / `B` 회사 공식 자료 / `C` 전문 매체·학술 / `D` 블로그·검색 요약

등급은 요약값입니다. IATA 문서는 산업 일반에는 A급이지만 특정 회사의 담보 금액은 입증하지 못합니다.

## 6. BSP 도메인 용어

아래 정의는 IATA `BSP Manual for Agents`(2021-09-01 발효)에 근거하며, 해당 Claim ID를 함께 적었습니다.

| 용어 | 뜻 | 근거 |
|---|---|---|
| BSP (Billing and Settlement Plan) | IATA 인가 여행사의 판매·환불·보고·송금 절차를 단순화하는 체계 | CL-001 |
| PSAA (Passenger Sales Agency Agreement) | 여객판매대리점계약. BSP Manual이 이 계약의 일부 | CL-002 |
| held in trust (신탁 보유) | 여행사가 고객에게서 받았으나 BSP 송금 전인 현금 판매대금의 상태 | CL-003 |
| Reporting period / Billing date / Remittance date | BSP 캘린더가 정하는 보고기간·청구일·송금기한 | CL-005 |
| Clearing Bank (청산은행) | 송금액을 수령하는 IATA 지정 은행 | CL-004 |
| ADM / ACM | 항공사가 발행하는 차변·대변 메모(사후 조정거래) | CL-006 |
| RHC (Remittance Holding Capacity) | 송금 대기 중인 BSP 현금 판매액의 상한 | CL-007 |
| Financial Security | 인가 유지를 위해 여행사가 제공하는 담보. 형태는 시장별로 다름 | CL-008, CL-011 |
| LFC (Local Financial Criteria) | 담보 금액 산정에 쓰이는 시장별 기준 | CL-009 |
| Cash Facility | 현금 결제수단 사용 권한. 보유 여부에 따라 담보 요건이 달라짐 | CL-008, CL-013 |

## 7. 회계·감사 용어 사용 원칙

- "유의적 위험", "부적정", "감사의견"은 이 시스템이 만들어 내지 않습니다.
- 위험은 항상 "…할 가능성이 있어 추가 확인이 필요합니다" 형태로 씁니다. 이 형식은 테스트 T14가 강제합니다.
- 계정과목은 "예상 계정"으로만 표시하며, 회사의 실제 계정체계로 확인되기 전에는 사실이 아닙니다.
