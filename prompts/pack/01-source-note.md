## 교정 사전 만드는 법

자동자막은 도메인 고유명사를 일관되게 틀린다. 교정 사전이 없으면 노트 전체에 오표기가 번지고, P2 통합에서 같은 회사가 두 개로 갈라진다.

1. 원문을 훑어 **뜻이 안 통하는 고유명사·전문용어**를 모은다.
2. 같은 대상을 가리키는 서로 다른 표기를 한 줄로 묶는다.
3. `| 오표기 | 정정 |` 2열 표로 만들어 `{{교정사전}}`에 붙인다.
4. **확실한 것만 넣는다.** 애매하면 사전에 넣지 말고 프롬프트가 `[불명확: 원문 "..."]`로 남기게 둔다.

# 1. 무손실 원칙 (최우선)

성공 기준은 "읽기 좋은가"가 아니라 **"원본에 있던 정보 중 노트에 없는 것이 없는가"** 다. 아래는 전부 살린다.

1. **모든 숫자** — 금액·비율·배수·수량·기간·연도. 반올림·생략 금지
2. **모든 고유명사** — 기업·인명·기관·지수·데이터 제공처
3. **모든 인과 사슬** — "왜 그런가". 결론만 남기고 근거를 자르지 말 것
4. **화자의 판단·전망** — 사실과 구분해 표기하되 삭제 금지
5. **비유·예시** — 이해 장치다. 이 산업을 모르는 사람에게는 비유가 본문보다 오래 남는다
6. **산업 관행과 비공식 규칙** — 계약 관행, 대금 수취 관행, 업계 통념. **④ 거래구조 이해에 직결되므로 최우선 보존**
7. **역사적 사건과 그 결과** — 특히 산업 전체가 크게 흔들린 사건
8. **화자의 인식 변화** — "예전엔 A로 봤는데 지금은 B" 류

**버릴 것**: 발화 잡음(어/자/예/[음악]/[박수]), 말 더듬 반복, 인사말, 리포트의 투자의견·목표주가·면책조항.
단, **촬영일시·강의 길이·다음 편 예고는 보존한다.** 정보 시점 확정과 시리즈 연결에 필요하다.

# 4. 표기 규칙

- **확신도**를 문장·행 단위로 붙인다.

| 표시 | 의미 |
|---|---|
| (확인) | 공시·계약서·회사 자료로 확인된 것 |
| (통설) | 업계에서 그렇다고 알려진 것. 이 회사도 그런지는 미확인 |
| (전언) | 누군가 말한 것. 사실 여부 미검증 — 유튜브 강의는 원칙적으로 전부 여기 |
| **(빈칸)** | 아직 모르는 것 → 인터뷰·공시로 채울 대상 |

- **(빈칸)이 이 노트에서 가장 값진 항목이다.** 아는 것을 늘리는 것보다, 모른다는 걸 아는 게 인터뷰 준비다.
- **사실 / 출처의 견해 / 리서처 주석**을 구분한다. 네가 회계지식으로 덧붙인 건 반드시 `(리서처 주석)`
- 숫자는 원문 단위 유지. 임의 환산 금지
- 시점 의존 정보는 "2024년 3월 기준" 식으로 시점 명기
- 화자가 같은 수치를 두 번 다르게 말하면 **임의로 통일하지 말고 병기**하고, 번복 사실 자체를 기록한다
- 이모지는 ⭐ 🎯 💬 💡 만 사용

# 5. 실행 절차

**Pass 1 (내부)** 원문을 순서대로 훑어 "정보 원자" 목록 작성. 숫자 1개·기업명 1개·인과관계 1개가 각 1원자. 30분 강의 기준 150~250개가 정상.
**Pass 2 (내부)** 각 원자를 구조에 배정. 안 들어가는 원자가 있으면 **섹션 신설**. 버리지 않는다.
**Pass 3** 집필.
**Pass 4** 노트 끝에 검증 출력:

```
## ✅ 커버리지 (Pass 4)
- 원자 N개 / 반영 N개
- 미반영: 없음 | (전부 나열 + 사유)
- 숫자 전수 대조: 통과 | 누락 목록
  (수치를 전부 나열해 원문과 1:1로 맞춘다. 교정한 수치는 원문 병기)
- 고유명사 전수 대조: 통과 | 누락 목록
  (기업/기관/인명을 전부 나열)
- 리서처 주석 N건 (모두 표시 확인)
- ④ 거래구조 (빈칸) N건
```

누락이 있으면 출력 전에 스스로 보완하고 재검증한다.

원문이 길면 주제 단위 3~5청크로 나눠 Pass 1~3 수행 후 통합, Pass 4는 전체 1회. 중간에 "계속할까요" 묻지 말고 끝까지 진행한다.
