# 조선업 통합 용어사전 (Part 1~8 합본)

> **출처**: 조선업 소스노트 Part 1~8의 「5. 용어 사전」 전편 + Part 1 「6. 밸류체인 지도」의 품목·약어.
> **표기 규칙**
> - ⭐ = 화자가 "외우세요 / 꼭 아셔야 된다"고 강조했거나 반복한 용어.
> - 출처 열의 `P1`~`P8` = 해당 용어가 등장한 소스노트 편. 여러 편이면 전부 표기.
> - "회계로 치면" 열이 `-` 인 것은 재무제표와 직접 닿는 항목이 없다는 뜻이다. **기술용어는 `-`가 정상이다.** 그래도 인터뷰에서 못 알아들으면 대화가 끊기므로 전부 수록했다.
> - 정의가 편마다 다른 용어는 각 절에 대표 정의를 두고, **5-10에 양쪽을 병기**했다.

## 5. 통합 용어사전 ⭐

### 5-0. 인터뷰 즉응 30선 — 이것만은 외우고 들어간다

> 담당자가 이 말을 던지는 순간 **되묻지 말고 바로 반응**해야 하는 30개. 거래구조·대금·원가·추정에 직결되는 순서로 골랐다.
> 맨 오른쪽 칸은 **그 자리에서 그대로 읽으면 되는 문장**이다.

| 담당자가 쓰는 말 | 뜻(한 줄) | 이 말이 나오면 떠올릴 회계 이슈 | 이어서 던질 질문(한 문장 의문문) |
|---|---|---|---|

| **스탠더드(방식)** | 계약·절단·탑재·진수·인도 5단계에 20%씩 균등 수취 | 청구 시점 = 마일스톤, 계약자산 상대적 축소 | 최근 신규 계약은 스탠더드로 돌아온 게 있나요, 아니면 여전히 헤비테일인가요? |

| **탑재** | 블록을 올려 선체를 조립하는 단계 | 진행률 마일스톤, 대금 청구 시점 | 탑재 시점 기준 진행률과 청구율 사이에 차이가 큰 호선이 있나요? |
| **진수** | 배를 바다에 띄우는 것 | 진행률 마일스톤, 대금 청구 시점 | 올해 진수 예정이었는데 밀린 호선이 있나요, 밀린 사유가 뭔가요? |
| **인도** | 발주처에 배 키를 넘기는 것 | 잔금 수취, 계약 종료·수익인식 마무리 | 인도 지연으로 지체상금(LD)이 걸린 호선이 있나요? |
| **슬롯** | 배를 지을 도크 공간을 미리 잡는 계약 | 생산능력 배분, 납기·매출 인식 시기 | 2년 뒤 슬롯이 다 찼다면 지금 수주분은 언제 매출로 들어오나요? |
| **수주잔고(백로그)** | 아직 매출로 인식되지 않은 확정 수주 물량 | 잔여 수행의무(K-IFRS 1115), 매출 가시성 | 잔고 중 계약 변경·취소 협의 중인 물량이 얼마나 되나요? |

| **척당 단가** | 선박 1척당 계약금액 | 계약별 거래가격, 수주 공시 검증 | 이 호선 척당 단가가 공시된 금액과 같나요, 옵션분은 어떻게 잡았나요? |
| **후판** | 두께 6mm 이상 두꺼운 철판. 건조원가의 약 20% | 원재료비 최대 항목, 총계약원가 추정 | 후판 가격이 오르면 이미 수주한 호선 예정원가를 언제 다시 잡나요? |
| **외주** | 블록·데크하우스 등을 기자재사에 맡기는 것 | 외주가공비, 기자재사 입장에서는 매출 | 이번 분기 외주 비중이 올라간 이유가 물량인가요, 인력 부족인가요? |
| **블록** | 선체를 레고처럼 쪼갠 대형 조립 단위 | 재고자산·외주 매출 단위 | 블록 제작이 밀린 게 원가 초과로 이어진 호선이 있나요? |
| **화물창** | 배가 실어 나르는 화물(LNG 등)을 담는 통 | 공사원가의 핵심, 하자·성능 보증 | 화물창 방식이 마크III인가요 NO96인가요, 그에 따라 원가가 얼마나 다른가요? |

| **로열티** | 라이선스 대가로 원천기술사에 지급하는 금액 | 매출원가 내 기술사용료, 지급수수료 | 로열티를 선급으로 내나요, 매출 인식에 맞춰 안분하나요? |
| **엔진 라이선스** | MAN·WinGD 등에서 엔진 제조 권리를 받는 것 | 무형자산·기술사용료, 관계사 거래 | 라이선스 계약이 몇 년짜리고, 재계약 조건이 바뀐 게 있나요? |
| **리드 타임** | 만들어 납품하기까지 걸리는 시간(선박 엔진 약 2년) | 재고 체류기간, 수주-매출 시차 | 리드 타임 2년이면 지금 잡힌 원가는 어느 시점 단가로 계산된 건가요? |
| **가동률** | 설비 이용 수준 | 고정비 배부·정상조업도, 미배부 고정비 | 가동률이 100%를 넘는데 초과분 고정비는 어떻게 배부하고 있나요? |
| **고가 선박 비중** | 높은 선가에 수주한 선박의 매출 비중 | 매출총이익률 동인, 마진 추정 | 고가 호선 비중이 몇 %고, 저가 호선은 언제 다 빠지나요? |
| **선주** | 배를 발주·소유·운항하는 주체(고객) | 고객 식별, 매출채권·계약자산 | 이 선주와의 계약에서 스펙 미달 배상 조항이 발동된 적이 있나요? |
| **FID(최종투자결정)** | 발주처가 프로젝트 투자를 최종 확정하는 것 | 수주 파이프라인의 확정 시점 | FID가 안 난 프로젝트를 수주 전망에 넣고 계신 건 아닌가요? |
| **EPC** | 설계·조달·시공 일괄 도급 | 계약 형태, 수행의무 식별 | EPC 계약에서 우리 몫이 어디부터 어디까지인가요? |
| **레트로핏(개조)** | 기존 선박을 규제 충족 사양으로 고치는 것 | 개조 매출(별도 수행의무), 시점 인식 | 개조 공사는 신조와 달리 언제 매출로 인식하나요? |
| **LTSA** | 3년·5년 단위 장기 부품 서비스 공급 계약 | 계약자산·계약부채, 장기계약 수익인식 | LTSA는 기간에 걸쳐 인식하나요, 부품 인도 시점에 인식하나요? |
| **교체용(After-market)** | 운항 중 선박의 소모품 교체 수요 | 반복 매출, 신조와 다른 인식 시점 | 교체용 매출과 신조용 매출을 구분해서 관리하고 계신가요? |
| **벤더 등록(인증)** | 조선사·오일메이저의 승인 협력업체 목록 등재 | 진입장벽, 매출처 집중도 | 조선 3사에 다 등록돼 있나요, 등록이 취소되면 잔고는 어떻게 되나요? |
| **CII / EEXI** | 선박 탄소 규제. CII는 A~E 등급, EEXI는 현존선 포함 | 강제 교체·개조 수요 → 매출 인식 근거 | CII E등급 선박 개조 물량이 잔고에 얼마나 들어와 있나요? |

### 5-1. 계약·건조 프로세스

> 프로세스 순서(설계 → 발주 → 계약 → 건조 → 인도 → 사후 서비스)로 정렬했다.

| 용어 | 뜻 | 영문/약어 | 담당자가 이 말을 쓰는 상황 | 회계로 치면 | 출처 |
|---|---|---|---|---|---|
| 개념설계 | 프로젝트 초기의 기본 구상 설계 단계 | Conceptual Design | "개념설계 단계라 아직 발주는 아니에요" | - | P4 |
| 예비 설계 / 타당성 조사 | 발주 전 사업성 검토 단계. 아직 발주 안 됨 | Pre-FEED / Feasibility Study | "타당성 조사 중입니다" | 수주 파이프라인(계약 아님) | P4 |
| ⭐ **FEED** | **기본설계.** 설계 전반부와 후반부를 연결. 핵심은 **타당성 평가**. **FEED가 끝나야 입찰·발주로 넘어간다** | Front End Engineering Design | 프로젝트 단계 논의 | 수주 파이프라인 | P3 |
| ⭐ **EPC** | **설계(Engineering)+조달(Procurement)+시공(Construction)** 을 한 번에 맡기는 일괄도급. 셋을 다 하는 회사가 종합건설사(대표: 삼성엔지니어링) | EPC | "EPC 발주 나왔대" | 계약 형태·수행의무 식별 (피팅사 입장에선 발주처) | P3·P4 |
| 입찰 | 여러 업체가 경쟁해 사업을 따는 절차. FEED 이후 | Bidding | "두 개 프로젝트 입찰 중" | - | P3·P4 |
| 견적 | 가격 제시 | Quotation | "견적 줬어요" | 계약 전 단계 | P4 |
| **FID (최종투자결정)** | 발주처가 프로젝트 투자를 최종 확정하는 것. **"FID 났냐"가 발주 신호** [원문 "최종 투자 결정"] | Final Investment Decision | 프로젝트 확정 여부 확인 | 수주 파이프라인의 확정 시점 | P8 |
| ⭐ **발주 / 발주사** | 선주·발주처가 배(또는 설비)를 주문하는 것, 또는 그 주체 | Order Placement / Owner | "발주 떨어졌어요" | 고객, 계약 체결 | P1·P2·P3·P4·P5 |
| ⭐ **수주** | 주문을 받아 계약을 따내는 것 | Order Received / Bookings | "올해 수주가 좋아요" | 계약 체결·계약잔액 | P1·P2·P4·P5 |
| 신규 수주 | 당기에 새로 딴 물량 | New Orders | 실적 발표 | 미래 매출 | P5 |
| 수주 목표 달성률 | 연간 수주 목표 대비 실적 비율 (삼성중공업 70%) | — | IR·실적 발표 | 수주잔고 선행지표 | P8 |
| ⭐ **수주잔고 (백로그)** | 수주했으나 아직 매출로 인식되지 않은 잔량. 동성화인텍 4년치, 한화엔진 매출의 3배 [원문 "수주 장고"] | Backlog / Order Backlog | "잔고 몇 년치냐" | **잔여 수행의무(K-IFRS 1115) / 계약부채** | P1·P3·P4·P5·P7·P8 |
| ⭐ **슬롯 (계약)** | **선박을 건조할 수 있는 공간(도크 자리)을 미리 확보하는 계약** | Slot | "잔여 슬롯 소진 → 프리미엄" | 생산능력(캐파) 배정 | P1·P7 |
| **도크** | 배를 짓고 수리하는 설비. **한국 조선사는 2027년까지 다 찼다** | Dock | 캐파·가동률 논의 | 유형자산 | P1·P3·P7·P8 |
| **야드** | **배를 만드는 공간(조선소)** | Yard | 캐파·생산능력 | 유형자산·생산설비 | P1 |
| ⭐ **RG (선수금환급보증)** | 은행·금융기관이 발급하는 **보증서**. **RG가 나와야 계약을 한다** [원문 "알지"] | RG (Refund Guarantee) | 수주 확정 여부, 금융 조건 | **우발부채·금융보증** | P1 |
| 선박금융 | 선박은 금액이 크고 "금융이 비싸서" 은행이 지원해 주는 금융 | Ship Finance | 발주처 자금조달 | 차입·보증 구조 | P1 |
| ⭐ **헤비테일** | **"꼬리가 무겁다"** — 대금의 대부분(60%)을 **인도 시점**에 받는 지급 방식. 금융위기 이후 확산 | Heavy Tail | 계약 조건 협상, 자금 계획 | **계약자산(미청구공사) 증가 요인** | P1 |
| **스탠더드 (방식)** | 계약·절단·탑재·진수·인도 **5단계에 20%씩 균등** 지급하는 원래 방식 | Standard | 계약 조건 비교 | 현금흐름 균등화, 마일스톤 청구 | P1 |
| **절단 (착공)** | 강재를 자르는 것 = **건조 착수**. "자 이제 우리 착공합니다" | Steel Cutting | 공정 진행 보고, 대금 청구 | 진행률 마일스톤 | P1 |
